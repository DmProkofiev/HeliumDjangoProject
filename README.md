# Helium - Маркетплейс услуг с системой рекомендаций

**Helium** - это соверменный маркетплейс, где заказчики размещают заказы на услуги (дизайн, программирование, ремонт, консультации), а исполнители откликаются на них. Встроенная система рекомендаций на основе правил и анализа поведения предлагает пользователям подходящие услуги и исполнителей.

![](https://github.com/DmProkofiev/HeliumDjangoProject/blob/main/static/img/CoverProject.jpeg)

Архитектура **MVT (Model-View-Template)**.  
Динамические части (автодополнение, чаты, уведомления) работают через AJAX и WebSocket (Django Channels).

---

## Основные возможности

### Для незарегистрированных пользователей
- Просмотр каталога услуг с фильтрацией по категориям, цене, рейтингу.
- Просмотр профилей исполнителей.
- Поиск услуг с автодополнением.

### Для заказчиков
- Регистрация аккаунта, вход по email/логин и паролю.
- Создание заказа (название, описание, бюджет, сроки, категория).
- Управление заказами: редактирование, удаление, просмотр откликов.
- Выбор исполнителя и закрытие заказа.
- Оплата через систему **эскроу** (YooKassa) - средства перечисляются исполнителю после подтверждения выполнения.
- Оставление оценки и отзыва исполнителю.
- Персональные рекомендации услуг и исполнителей на главной странице и в личном кабинете.

### Для исполнителей
- Заполнение профиля: навыки, портфолио, цена за час/проект.
- Отклик на заказы с комментарием и своей ценой.
- Уведомления о новых откликах и изменении статуса заказа.
- Чат с заказчиком в реальном времени.
- Рекомендации подходящих заказов на основе навыков и истории.

### Административная панель
- Кастомизированный Django Admin для управления пользователями, заказами, категориями.
- Просмотр статистики: количество заказов, средний чек, активность пользователей.

## Технологический стек

| Компонент   | Технология                                  | Назначение |
|-------------|--------------------------------------------|------------|
| Backend     | Django (MVT)                               | ORM, админка, views, templates |
| База данных | PostgreSQL + `pg_trgm`                     | Хранение, полнотекстовый и нечёткий поиск |
| Real-time   | Django Channels (WebSocket)                | Чаты, уведомления |
| Платежи     | YooKassa (тестовый режим)                  | Эскроу-счета |
| FrontEnd    | Django Templates + Bootstrap + JavaScript  | SSR, AJAX, WebSocket |

> **Рекомендации** реализованы на основе машинного обучения: используются библиотека skit-learn
>
> **Поиск** реализован на PostgreSQL (триграммы + полнотекстовый), Elasticsearch не используется.

## Структура проекта Django

| Приложение        | Назначение                                          |
|-------------------|-----------------------------------------------------|
| `accounts`        | Пользователи, роли (заказчик/исполнитель), профили, |
| `core`            | Основа для содержания публикаций, лента             |
| `orders`          | Заказы, отклики, статусы, коммерческие сделки       |
| `chat`            | Чаты и уведомления в реальном времени               |
| `recommendations` | Формирование персональных рекомендаций              |
| `payments`        | Интеграция с YooKassa (эскроу)                      |
