# Helium - Маркетплейс услуг с системой рекомендаций

**Helium** - это маркетплейс, где заказчики размещают заказы на услуги (дизайн, программирование, ремонт, консультации) или публикуют товары на продажу, а исполнители откликаются на них. Встроенная система рекомендаций на основе анализа поведения и содержимого публикаций предлагает пользователям подходящие услуги и исполнителей.

![](https://github.com/DmProkofiev/HeliumDjangoProject/blob/main/static/img/CoverImageProject.jpeg)

Архитектура **MVT (Model-View-Template)**.  
Динамические части (чаты) работают через WebSocket (Django Channels) и AJAX.

---

## Основные возможности

### Для незарегистрированных пользователей
- Просмотр каталога услуг и товаров с фильтрацией по категориям, тегам и цене.
- Просмотр профилей исполнителей.
- Подстрочный поиск услуг и товаров.

### Для заказчиков
- Регистрация аккаунта, вход по логину и паролю.
- Создание публикации (название, описание, бюджет, сроки, категория) или публикация товара на продажу.
- Управление публикациями: редактирование, удаление, загрузка и удаление фотографий.
- Оплата через систему **эскроу** (YooKassa) — средства перечисляются исполнителю после подтверждения выполнения.
- Оставление комментария к публикации, в том числе с прикреплением фотографий.
- Персональные рекомендации услуг и исполнителей на главной странице и в карточке публикации.

### Для исполнителей
- Заполнение профиля: имя, email, телефон, город, аватар.
- Публикация услуг и товаров с указанием цены, типа цены и срока выполнения.
- Чат с заказчиком в реальном времени.
- Получение рекомендаций публикаций на основе истории взаимодействий.

### Административная панель
- Кастомизированный Django Admin для управления пользователями, публикациями, категориями и тегами.

## Технологический стек

| Компонент   | Технология                                  | Назначение |
|-------------|--------------------------------------------|------------|
| Backend     | Django (MVT)                               | ORM, админка, views, templates |
| База данных | PostgreSQL                                 | Хранение данных |
| Real-time   | Django Channels (WebSocket)                | Чаты |
| Платежи     | YooKassa (тестовый режим)                  | Эскроу-счета |
| FrontEnd    | Django Templates + JavaScript              | SSR, AJAX, WebSocket |

> **Рекомендации** реализованы на основе машинного обучения: используется библиотека **scikit-learn** (TF-IDF и косинусное сходство).
>
> **Поиск** реализован на PostgreSQL средствами Django ORM (`icontains`). Elasticsearch и расширение `pg_trgm` не используются.

## Пакеты и библиотеки

Ниже перечислены пакеты, используемые в проекте, с определениями и описанием в соответствии с официальной документацией.

### Основной веб-фреймворк и ASGI

**Django** — высокоуровневый Python-веб-фреймворк, который поощряет быструю разработку и чистый, прагматичный дизайн. Предоставляет ORM, шаблонизатор, админ-панель, формы и маршрутизацию URL. Официальная документация: https://docs.djangoproject.com/en/stable/

**asgiref** — реализация спецификации ASGI (Asynchronous Server Gateway Interface) для Python. ASGI — это стандарт взаимодействия между асинхронными веб-серверами и приложениями, позиционируемый как асинхронный преемник WSGI. Официальная документация: https://asgi.readthedocs.io/

**channels** — проект, расширяющий возможности Django за пределы HTTP: поддержка WebSocket, протоколов чатов, IoT и других долгоживущих соединений. Построен на спецификации ASGI. Официальная документация: https://channels.readthedocs.io/

**daphne** — сервер протоколов HTTP, HTTP/2 и WebSocket для ASGI и ASGI-HTTP, разработанный для обеспечения работы Django Channels. Поддерживает автоматическое согласование протоколов без необходимости префиксации URL. Официальная документация: https://github.com/django/daphne

### База данных

**psycopg** (psycopg 3) — современный адаптер PostgreSQL для Python, реализующий спецификацию Python DB API 2.0 и предоставляющий нативную поддержку asyncio. Официальная документация: https://www.psycopg.org/psycopg3/docs/

**psycopg-binary** — бинарная сборка psycopg, не требующая компиляции при установке.

> Расширение PostgreSQL `pg_trgm` в проекте **не используется**. Модуль `pg_trgm` предоставляет функции и операторы для определения схожести алфавитно-цифрового текста на основе сопоставления триграмм, а также классы индексных операторов GiST и GIN для быстрого поиска похожих строк.

### Рекомендации и машинное обучение

**scikit-learn** — библиотека машинного обучения для Python, предоставляющая простые и эффективные инструменты для интеллектуального анализа данных и анализа. В проекте используется `TfidfVectorizer` для преобразования текста публикаций в матрицу TF-IDF-признаков и `linear_kernel` для вычисления косинусного сходства. Официальная документация: https://scikit-learn.org/stable/

**scipy** — открытое программное обеспечение для математики, науки и инженерии. Является фундаментальной зависимостью scikit-learn. Официальная документация: https://docs.scipy.org/doc/scipy/

**numpy** — фундаментальный пакет для научных вычислений на Python, предоставляющий поддержку больших многомерных массивов и матриц, а также коллекцию математических функций. Официальная документация: https://numpy.org/doc/stable/

**joblib** — пакет для параллельных вычислений и дискового кэширования на Python, оптимизированный для больших данных и массивов NumPy. Используется как зависимость scikit-learn. Официальная документация: https://joblib.readthedocs.io/

### Платежи

**yookassa** — Python SDK для работы с платежами по API ЮKassa. Позволяет создавать, подтверждать и отменять платежи, а также получать информацию о них. Официальная документация: https://github.com/yoomoney/yookassa-sdk-python

**requests** — элегантная и простая HTTP-библиотека для Python, позволяющая легко отправлять HTTP/1.1 запросы. Используется как зависимость yookassa и других пакетов. Официальная документация: https://requests.readthedocs.io/

### Работа с изображениями и конфигурацией

**Pillow** — дружественный форк Python Imaging Library (PIL), добавляющий в интерпретатор Python возможности обработки изображений, включая обширную поддержку форматов файлов и мощные средства обработки. Официальная документация: https://pillow.readthedocs.io/

### Транзитивные зависимости (обеспечивают работу ASGI-стека и платежей)

**Twisted** — событийно-ориентированный сетевой движок для Python, на котором работает Daphne. Официальная документация: https://twisted.org/

**Autobahn** — подпроект Autobahn, предоставляющий открытые реализации протокола WebSocket (RFC6455) и WAMP для Python, работающие под Twisted и asyncio. Официальная документация: https://autobahn.readthedocs.io/

**cryptography** — пакет, предоставляющий криптографические рецепты и примитивы для разработчиков Python, включая высокоуровневые рецепты и низкоуровневые интерфейсы к распространённым криптографическим алгоритмам. Официальная документация: https://cryptography.io/

**pyOpenSSL** — Python-обёртка для библиотеки OpenSSL, обеспечивающая поддержку TLS в Daphne.

**service-identity** — проверка идентичности сервисов, используется в TLS-стеке Twisted.

**cffi** — C Foreign Function Interface для Python, используется библиотекой `cryptography` для вызова функций из библиотек, написанных на C.

**pycparser** — парсер кода на C, используемый как зависимость `cffi`.

**attrs** — пакет для определения классов с атрибутами, используется в Twisted и Autobahn.

**Automat** — библиотека для создания конечных автоматов, зависимость Twisted.

**constantly** — библиотека символических констант, зависимость Twisted.

**hyperlink** — библиотека для работы с URL, зависимость Twisted.

**Incremental** — библиотека версионирования, зависимость Twisted.

**zope.interface** — реализация интерфейсов для Python, зависимость Twisted.

**txaio** — абстракция асинхронного ввода-вывода, позволяющая Autobahn работать как с Twisted, так и с asyncio.

**cbor2** — кодек CBOR (Concise Binary Object Representation), зависимость Autobahn.

**msgpack** — реализация формата сериализации MessagePack, зависимость Autobahn.

**ujson** — ультрабыстрый JSON-кодек, зависимость Autobahn.

**certifi** — набор корневых сертификатов для проверки SSL-сертификатов, зависимость `requests`.

**charset-normalizer** — библиотека для определения кодировки текста, зависимость `requests`.

**idna** — поддержка интернационализированных доменных имён (IDNA), зависимость `requests`.

**urllib3** — мощный HTTP-клиент для Python, зависимость `requests`.

**sqlparse** — парсер SQL, зависимость Django.

**packaging** — утилиты для работы с версиями пакетов и спецификаторами.

**typing_extensions** — обратно совместимые аннотации типов для старых версий Python.

**tzdata** — база данных часовых поясов.

**cloudpickle** — расширенная сериализация Python-объектов, зависимость `joblib`.

**threadpoolctl** — контроль пулов потоков в сторонних библиотеках, зависимость scikit-learn.

**Deprecated** — декоратор для пометки устаревших функций, зависимость `yookassa`.

**wrapt** — библиотека декораторов и обёрток, зависимость `Deprecated`.

**distro** — определение дистрибутива Linux, зависимость `yookassa`.

**narwhals** — слой совместимости для фреймов данных, транзитивная зависимость.
